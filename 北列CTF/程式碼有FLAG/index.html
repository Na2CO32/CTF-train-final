WEB CHALLENGE · CHAPTER 03

求婚大作戰 💍

帶著找回的禮物 🎁 和剛取到的花束 💐，小明 的約會非常順利，女朋友笑得好開心。

晚餐後，兩人來到河堤邊看夜景。小明 深吸一口氣，單膝跪下，把手伸進口袋準備拿出戒指——

……口袋是空的！😨

這時 小明 才想起來：怕戒指弄丟，早就把戒指「收進」了這張為女朋友做的求婚網頁裡，還對自己說過一句話：「真正重要的東西，不會擺在表面上。」

🎯 任務目標

女朋友還在等著呢！請幫 小明 找出藏在這個靜態網頁中的戒指 Flag。請只使用瀏覽器內建的開發者工具，不需要登入，也不需要安裝任何東西。

提示

提示 1：從哪裡開始？

先打開瀏覽器的開發者工具。你可以按 F12，或在頁面上按右鍵並選擇「檢查」。

提示 2：看哪裡？

畫面上看不到，不代表原始碼裡沒有。試著查看這個頁面的 HTML，並留意看起來不像一般文字的內容。

提示 3：線索的形式

有些文字會使用一種常見的編碼方式表示。若內容由英文字母、數字，以及偶爾出現的 = 組成，可以思考它可能是什麼格式。

🚩 FLAG 驗證器

規則：不需要暴力破解。仔細觀察原始碼，逐步找出線索即可。

找到戒指後，把 FLAG 拿到驗證平台登記，見證 小明 的求婚結果吧！
