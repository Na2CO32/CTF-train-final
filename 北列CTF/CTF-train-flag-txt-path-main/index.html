WEB CHALLENGE · CHAPTER 01

遺失的禮物 🎁

今天是 小明 和女朋友交往一週年的約會日。

小明 早就準備好一份神秘禮物，為了不讓女朋友提前發現，還特地把它藏在這個網站的某個角落……

沒想到出門前，小明 才驚覺——自己完全忘記禮物藏在哪裡了！😱

距離約會只剩一個小時，請你幫 小明 把禮物找回來！

🎯 任務目標

🧠 小明 努力回想：「我記得……我有跟網站上的搜尋引擎機器人說過，有個地方絕對不准任何人進去偷看……」請找出藏在這個網站裡的禮物 Flag。

提示

提示：還是想不起來？

在網址後面輸入 /robots.txt 試試看吧？

🚩 FLAG 驗證器

找到禮物後，也可以把 FLAG 拿到驗證平台登記。
